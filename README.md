# Spotify Clone

A front-end clone of Spotify's web player built using HTML and CSS.

## About the Project

This project recreates the user interface of Spotify, including the sidebar, navigation menu, music cards, and music player section. It was created to practice modern HTML and CSS layout techniques.

## Features

- Spotify-inspired UI
- Sidebar navigation
- Music playlist cards
- Responsive layout
- Modern design using CSS

## Technologies Used

- HTML5
- CSS3
